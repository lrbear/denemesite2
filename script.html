🎮 Oyun İçi Lua Hub Kodun (Otomatik Senkronize)

Bu Lua kodunu kendi oyun içi scriptine ekleyebilirsin. Siteden eklediğin her script direkt bu koda yansır.

local HttpService = game:GetService("HttpService") local firebaseURL = "https://klakz-database-default-rtdb.firebaseio.com/scripts.json" local success, response = pcall(function() return HttpService:JSONDecode(HttpService:GetAsync(firebaseURL)) end) if success and response then for id, scriptData in pairs(response) do local oyunAdi = scriptData.title print("Siteden gelen oyun: " .. oyunAdi) -- Buraya kendi UI buton oluşturma kodlarını yazabilirsin end end
